1. Einführung in Atlas Browser

Atlas Browser ist ein webbasierter Micro-Browser und Web-Betriebssystem. Er ermöglicht es dir, eigene Webseiten direkt im Browser zu coden, mit einem Klick zu publizieren und native atlas://-Adressen zu nutzen.

⚡ Highlights

  • Native Protokolle: Navigiere über atlas://home, atlas://editor oder eigene Seiten mit atlas://site/<name>.
  • Echtzeit-Editor: HTML-, CSS- und JavaScript-Entwicklung mit sofortiger Live-Vorschau.
  • Offline & Cloud: Seiten werden wahlweise über die API synchronisiert oder im lokalen Speicher gesichert.
  • Vercel Ready: 100% optimiert für Vercel mit statischem SPA-Routing und Serverless Functions.

2. Das atlas:// Protokoll

Atlas Browser besitzt ein eigenes URL-Schema für interne Funktionen und Seiten:

URL Beschreibung
atlas://home Die Haupt-Startseite mit Suchleiste und Schnellzugriff
atlas://editor Der Code-Editor für eigene HTML/CSS/JS Projekte
atlas://store App- und Spiele-Katalog mit installierbaren Demos
atlas://community Übersicht veröffentlichter Community-Seiten
atlas://docs Diese Dokumentation
atlas://settings Themes, Suchmaschine und Speicheroptionen
atlas://site/:name Lädt eine gespeicherte Atlas-Seite (z. B. atlas://site/snake)

3. Seiten bauen im Atlas Editor

Jede Atlas-Seite besteht aus drei Komponenten:

  • HTML: Die Dokumentstruktur und Inhalte.
  • CSS: Design, Animationen und Layouts.
  • JavaScript: Interaktion, Logik und Canvas-Rendering.
Beispiel: Interaktive Schaltfläche
// Im JS-Tab:
document.getElementById("btn").addEventListener("click", () => {
  alert("Hallo aus dem Atlas Browser!");
});

Mit der Taste ▶ Run oder dem Shortcut Strg + Enter wird die Live-Vorschau neu gerendert.

4. Atlas REST API Referenz

Die API erlaubt das programmatische Speichern und Abrufen von Seiten:

POST /api/publish

Veröffentlicht eine neue Seite.

{
  "name": "meineseite",
  "html": "<h1>Titel</h1>",
  "css": "body { color: cyan; }",
  "js": "console.log('ready');",
  "author": "DeinName"
}
GET /api/site/:name

Gibt das JSON-Objekt der Seite zurück.

GET /api/sites

Gibt alle registrierten Seiten als Liste zurück.

5. Vercel Deployment Guide

So stellst du sicher, dass dein Vercel Deployment fehlerfrei läuft:

  • Kleinschreibung: Alle Kern-Dateien (index.html, app.js, style.css, server.js) müssen kleingeschrieben sein, da Linux-Server Dateinamen strikt case-sensitive behandeln.
  • vercel.json: Stellt sicher, dass das SPA-Routing aktiviert ist und /api/* automatisch auf Serverless Functions geleitet wird.
